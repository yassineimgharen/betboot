# Current scope

The supported application is `python main.py`: three questions followed by automated
research and a compact manual betting slip. The previous dashboard roadmap is retired.

Implemented: five-league fixture discovery, optional historical bootstrap, authorized
context/odds integrations, statistical forecasts, calibration and uncertainty gates,
final fixture verification, one selection per match, source audits and honest abstention.

External limits remain: provider entitlements, current quote availability, context coverage,
and enough independent observations to validate each league/market model. Imported xG
requires adequate timestamped history and held-out validation before it can justify picks.
No guaranteed win rate or demonstrated profitability is claimed.

See README.md for operation and VALIDATION.md for executed checks.
